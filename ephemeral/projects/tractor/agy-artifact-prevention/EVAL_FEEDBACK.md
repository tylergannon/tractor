# Evaluation feedback

1. **Critical — the required prevention contract is absent.** The current acceptance criteria require a Tractor-owned custom-agent manifest, `--agent <tractor-owned-name>` on every agy turn, and an `init.tools` invariant that rejects any of `write_to_file`, `replace_file_content`, or `multi_replace_file_content` and rejects a missing `run_command` while tolerating unrelated tools. Instead, `harness/agy/adapter.go:516-536` constructs every invocation without `--agent`; `harness/agy/schema/protocol.json:15-21` and `harness/agy/schema/types_gen.go:24-32` do not model `init.tools`; and the init handler at `harness/agy/adapter.go:588-596` checks only conversation identity. No manifest is present anywhere in the diff. `WORK_SUMMARY.md:26-79` explicitly says this contract was dropped under an earlier in-pipeline ruling, but the current supervisor request explicitly reinstates it and is authoritative for this validation. Implement the manifest/argument/invariant contract, including focused tests for both forbidden-writer and missing-`run_command` failures. If the empirically observed agy 1.1.15 behavior makes that contract impossible, route the task back as blocked instead of substituting a different design and claiming completion.

2. **Critical — the substitute prevention layer is persistent global policy, not Tractor-scoped selection.** `Adapter.runOnceWithActive` always calls `ensureHook` before invoking agy (`harness/agy/adapter.go:502-517`), and `ensureNativeWriteHook` permanently merges policy into the user's global `~/.gemini/config/hooks.json` (`harness/agy/native_write_hook.go:115-120,240-323`). That hook affects unrelated interactive agy sessions because it is globally active without a Tractor-only `--agent` selection; it also makes every Tractor session fail before launch on an older or unparseable agy version. The requested custom agent would be inert unless Tractor selected it and would answer the shared/isolated-worktree placement requirement without changing unrelated sessions. Remove the global-hook substitution from this deliverable and use a clearly Tractor-owned, collision-safe manifest placement that is idempotent and does not write into branch workspaces.

3. **Issue — the ae5edb6 repair fallback was materially rewritten rather than kept intact.** The committed fallback resumes the existing conversation and instructs shell-only rewriting. The diff now prepends `artifactMetadataPromptPreamble` to every normal turn (`harness/agy/adapter.go:200-207,868-890`), starts the repair as a fresh `--new-project` conversation, remaps later calls through `agyConversationID`, and tells the model to retry native writers without `ArtifactMetadata` (`harness/agy/adapter.go:220-248,881-892`). That is a broad semantic change with new conversation-context behavior, not the requested addition of prevention while retaining the known fallback. Restore the ae5edb6 repair path and its original regression expectations, then layer the manifest prevention and `init.tools` guard ahead of it. Any redesign of recovery should be proposed and authorized separately from this narrowly specified prevention change.
